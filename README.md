# analiza-strony

Skill Claude Code: analiza strony leada pod sprzedaż. Wynik w rozmowie, 5-7 krótkich punktów do poprawy.

## Co sprawdza (checklista)

**Strona**
- render ze scrollem i screenshotem (Playwright), platforma i fundament techniczny
- konwersja: CTA, formularz, ścieżka do kontaktu
- wydajność i mobile
- SEO podstawy: title, opisy, nagłówki, indeksacja

**Analityka**
- pomiar po akceptacji cookies: GA4, GTM, piksel Meta, CAPI
- zgoda i temat prawny (cookies, polityka prywatności)
- lejek i lista mailingowa: czy jest zapis, do czego prowadzi

**Google**
- realny SERP na frazy lokalne
- wizytówka Google, opinie

**Reklamy Meta**
- Ad Library: czy lead reklamuje się, dokąd prowadzą reklamy

**Werdykt:** nowa strona czy poprawki (uczciwe "nieuzasadniony" ważniejsze niż sprzedany rebuild).

Każde twierdzenie jest mierzone dwiema niezależnymi metodami. Dalej: checkpoint w rozmowie, potem draft maila w Gmailu.
